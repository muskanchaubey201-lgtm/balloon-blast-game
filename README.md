# 🎈 Balloon Blast Game

A fun and interactive balloon shooting game developed using PHP, HTML, CSS and JavaScript.

## 🎮 About the Game

Balloon Blast is a browser-based shooting game where the player tries to shoot as many balloons as possible before the time runs out.

## ✨ Features

- 🎈 Balloon shooting gameplay
- 🎯 Score system
- ⏱️ Countdown timer
- ❤️ Lives system
- ✨ Smooth animations
- 🎨 Attractive user interface
- 🏆 Final score display

## 🛠️ Technologies Used

- PHP
- HTML5
- CSS3
- JavaScript
